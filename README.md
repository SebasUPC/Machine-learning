# ALDIMI Core AI — Trabajo Final Machine Learning

Dashboard interactivo para priorizacion preventiva, inventario predictivo y analisis estrategico de ALDIMI 2.0.

## Requisitos

- Python 3.10+
- Dependencias en `requirements.txt`

## Instalacion

```bash
pip install -r requirements.txt
```

## Ejecutar dashboard

```bash
streamlit run streamlit_app.py
```

## Estructura

| Carpeta / archivo | Descripcion |
|---|---|
| `streamlit_app.py` | Dashboard ALDIMI Core AI |
| `src/` | Notebooks del pipeline (descarga, merge, EDA, modelado) |
| `data/processed/` | Datasets listos para el dashboard |
| `docs/Seccion_III_IV_V_Fabian.md` | Contenido del informe (MLOps, ODS, Ecosistema) |

## Secciones del dashboard

- **Operacion diaria**: Resumen ejecutivo, inventario predictivo, priorizacion clinica
- **Analisis de datos**: Menu estadistico interactivo
- **Estrategia y gobierno**: MLOps, impacto ODS y etica, ecosistema Core AI
